# docs/

Enam dokumen di folder ini adalah **sumber kebenaran** untuk repo ini. Disalin byte-identik
dari folder kerja `FILE KERJA AFFILIATE` pada 10 Oktober 2026, jadi isinya belum diubah.

## Aturan penyuntingan

- Sunting dokumen **di sini**, jangan di salinan folder kerja. Kalau dua-duanya disunting, akan ada
  dua versi yang berbeda dan AI akan menebak mana yang benar.
- Salinan di folder kerja statusnya **arsip** dan boleh dihapus setelah Anda yakin.
- Perubahan skema database wajib memperbarui `skema-database.md` pada migrasi yang sama
  (aturan 9 di `AGENTS.md`).
